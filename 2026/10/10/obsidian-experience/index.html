Obsidian 初体验：我的知识管理工具选择

2026年10月10日 {% if page.categories.size > 0 %} {% endif %} {% if page.tags.size > 0 %} {% endif %}

为什么选择 Obsidian？

在尝试了多款笔记软件之后，我最终选择了 Obsidian 作为我的个人知识管理工具。以下是我选择它的几个主要原因：

1. 本地文件，数据安全

Obsidian 的所有笔记都以 Markdown 格式存储在本地，你完全拥有自己的数据。不用担心平台关闭、数据丢失或导出困难的问题。

你的数据就是你的，永远在你自己的电脑上。

2. 双向链接，构建知识网络

Obsidian 最强大的功能之一就是双向链接。通过 [[笔记名称]] 的语法，你可以快速在笔记之间建立联系，逐渐形成自己的知识网络。

3. 插件生态，高度可定制

Obsidian 拥有丰富的社区插件生态，你可以根据自己的需求定制功能：

  • 核心插件：标签、搜索、大纲、反向链接等
  • 社区插件：日历、看板、思维导图、任务管理等
  • 主题：丰富的外观主题可选

4. Markdown 原生支持

完全基于 Markdown，学习成本低，迁移方便，而且与 AI 工具完美配合。

我的 Obsidian 配置

必备插件

  1. Calendar - 日历视图，方便日记和每日笔记
  2. Templater - 模板插件，快速创建标准化笔记
  3. Dataview - 数据查询，像数据库一样管理笔记
  4. Excalidraw - 手绘风格图表

笔记分类方式

我目前的笔记结构是这样的：

📁 000 - 每日笔记
📁 100 - 学习笔记
   📁 新媒体交互设计
   📁 编程开发
📁 200 - 项目笔记
📁 300 - 读书摘录
📁 400 - 生活记录
📁 900 - 归档

使用感受

使用 Obsidian 一段时间后，最大的感受是：知识不再是孤立的碎片，而是逐渐连接成网。

当你在写新笔记时，看到反向链接里跳出以前写过的相关内容，那种"原来我之前想过这个问题"的惊喜感，是其他笔记软件很难给到的。

与 AI 结合的工作流

我目前的知识管理工作流是这样的：

  1. 输入：看书、上课、浏览文章时，随手记录想法
  2. 整理：定期用 AI 辅助整理笔记，提炼要点
  3. 连接：在 Obsidian 中建立笔记之间的链接
  4. 输出：基于笔记写博客文章，分享知识

输入 → 整理 → 连接 → 输出，形成完整的知识循环

总结

Obsidian 不仅仅是一个笔记工具，它更像是一个第二大脑，帮你存储、连接和产出知识。

如果你也在寻找一款适合自己的知识管理工具，不妨试试 Obsidian，说不定它也会成为你的效率神器。
