用 Jekyll + GitHub Pages 搭建个人博客教程

2026年10月08日 {% if page.categories.size > 0 %} {% endif %} {% if page.tags.size > 0 %} {% endif %}

为什么要建个人博客？

在这个社交媒体泛滥的时代，为什么还要建一个个人博客呢？我觉得有以下几个原因：

  1. 拥有自己的数字花园：社交媒体的数据不属于你，但博客是你自己的
  2. 倒逼输入与输出：写博客能让你更认真地学习和思考
  3. 建立个人品牌：分享知识，结识志同道合的朋友
  4. 记录成长轨迹：多年后回头看，会很有成就感

技术选型

常见的静态博客生成器有这些：

生成器 与 GitHub Pages 关系 内容模型 适合 主要短板
Jekyll ✅ 原生，自动构建免 Actions 博客式（按日期文章） 个人博客、写作记录 Ruby 环境、构建较慢、插件白名单受限
MkDocs Material 需 Actions 文档/知识库（侧边目录） 结构化笔记、Wiki 需自己配部署
VitePress 需 Actions 现代文档 技术笔记 需 Node 环境
Hugo 需 Actions 任意（极快） 海量笔记 模板语法略陡

对于新手来说，Jekyll + GitHub Pages 是最简单的组合，因为：

  • GitHub Pages 原生支持 Jekyll，推送代码后自动构建
  • 不需要配置复杂的 CI/CD
  • 主题和插件生态成熟
  • 完全免费

准备工作

1. 注册 GitHub 账号

如果你还没有 GitHub 账号，先去 GitHub 官网 注册一个。

2. 安装 Git

下载并安装 Git，用于版本控制和代码推送。

3. （可选）安装 Jekyll 本地环境

如果想在本地预览博客效果，需要安装 Ruby 和 Jekyll。不过这一步可以先跳过，直接在 GitHub 上部署也行。

搭建步骤

第一步：创建仓库

  1. 在 GitHub 上新建一个仓库
  2. 仓库名可以叫 blog 或 assignment2（根据课程要求）
  3. 选择 Public（公开）
  4. 勾选 “Add a README file”

第二步：创建博客结构

在仓库中创建以下文件结构：

blog/
├── _config.yml          # 站点配置
├── index.html           # 首页
├── about.md             # 关于页
├── _posts/              # 文章目录
│   └── 2026-10-08-hello-world.md
├── _layouts/            # 布局模板
│   ├── default.html
│   ├── home.html
│   └── post.html
├── _includes/           # 可复用组件
│   ├── header.html
│   └── footer.html
└── assets/
    └── css/
        └── style.css    # 样式文件

第三步：配置 _config.yml

这是 Jekyll 的核心配置文件：

title: "我的博客"
description: "记录学习与成长"
author: "你的名字"
baseurl: ""
url: "https://yourname.github.io"

markdown: kramdown
permalink: /:year/:month/:day/:title/

第四步：写第一篇文章

在 _posts 目录下创建文件，文件名格式为 YYYY-MM-DD-文章标题.md：

---
layout: post
title: "Hello World!"
description: "我的第一篇博客文章"
date: 2026-10-08
categories: [随笔]
tags: [博客]
---

## 你好，世界！

这是我的第一篇博客文章。

第五步：开启 GitHub Pages

  1. 进入仓库的 Settings 页面
  2. 找到 Pages 选项
  3. 在 Build and deployment 下，Source 选择 Deploy from a branch
  4. Branch 选择 main 分支，目录选择 / (root)
  5. 点击 Save

稍等几分钟，你的博客就上线了！访问地址是：

https://你的用户名.github.io/仓库名/

注意：如果仓库名是 你的用户名.github.io，那么访问地址就是 https://你的用户名.github.io/，baseurl 留空即可。

写博客的小技巧

1. 用好 Front Matter

每篇文章开头的 YAML 配置叫 Front Matter，可以设置标题、日期、分类、标签等。

2. 图片怎么处理？

推荐使用图床服务，比如：

  • GitHub 仓库本身当图床
  • Gitee + PicGo
  • 各种云存储服务

3. 保持更新频率

不用追求每天都写，但尽量保持一定的更新频率，比如每周一篇。

常见问题

Q：构建失败怎么办？ A：检查 _config.yml 格式是否正确，YAML 对缩进要求很严格。

Q：怎么自定义域名？ A：在仓库设置的 Pages 页面里可以配置 Custom domain。

Q：可以用评论系统吗？ A：可以接入 Disqus、Utterances、Giscus 等第三方评论系统。

总结

搭建一个个人博客其实并不难，难的是坚持写下去。
