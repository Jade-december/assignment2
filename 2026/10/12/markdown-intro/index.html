Markdown 入门学习笔记

什么是 Markdown？

Markdown 是一种轻量级标记语言，由 John Gruber 于 2004 年创建。它用简单的符号来表示标题、强调和列表等格式，本质是给人写、给程序解析的纯文本格式。

Markdown 文件的后缀名是 .md，写文档很酷！

为什么要学 Markdown？

1. Markdown 是 AI 的"母语"

AI 最主流的输出格式就是 Markdown，原因有四：

  • 训练数据多：GitHub、文档、论坛大量使用 Markdown
  • 结构清晰：标题、列表、表格、代码块都能用简单符号表达
  • 易读易解析：人看着舒服，程序也容易转成 HTML
  • token 效率高：比 HTML 标签更省 token

2. 结构化思考

Markdown 不只是学写代码，更是学会结构化表达。当你用 Markdown 写需求时，你会先想清楚任务、背景、要求，而不是把所有想法揉成一段话。

五大核心语法

第一个：# 井号（标题）

标题不是为了把字变大，它的作用是先分层。自己写的时候不容易散，AI 看你的需求时也更容易知道每块内容在干什么。

# 一级标题
## 二级标题
### 三级标题

第二个：-/* 短横线（列表）

列表特别适合写要求，一条一条摆出来，AI 漏掉的概率会低一点，自己也能检查要求是不是太多了。

- 任务一
- 任务二
- 任务三

第三个：** 两个星号（加粗）

把重要的词或句子前后各加两个星号。但加粗不要滥用，满篇都加粗最后等于没加。

我一般只标两类东西：一个是结论，一个是我希望 AI 别忽略的限制条件。

第四个：> 大于号（引用）

引用最适合把原话和自己的判断分开写，笔记时尤其有用。

> 这是一段引用的内容

第五个：`` 反引号（精确信息）

把命令、字段名、产品名、文件名这类精确信息前后各加一个反引号。这个符号对 AI 提问特别有用。

请帮我解释 `useState` 这个 React Hook

标准提示词模板

用 Markdown 写 Prompt 可以大幅提升 AI 回答的质量。以下是标准提示词的 6 大构成：

部分 作用 是否必需
1. 角色 告诉 AI"你是谁" 推荐
2. 任务 告诉 AI"做什么" 必需
3. 背景 告诉 AI"为什么/在什么情况下做" 推荐
4. 要求 告诉 AI"怎么做" 必需
5. 输出格式 告诉 AI"结果长什么样" 推荐
6. 示例 给 AI 一个"参考答案" 可选

总结

Markdown 不难，难的是我们平时太习惯把一堆想法揉成一段话，然后丢给 AI 猜。

下次你问 AI 问题时，可以先别管别的，就把需求拆成三块：任务、背景、要求，先试一次，你很快会发现 AI 回答会更清楚，你自己也会更清楚。
